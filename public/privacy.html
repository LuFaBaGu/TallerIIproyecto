Política de Privacidad y Tratamiento de Datos Personales

Última actualización: 24 de noviembre de 2026

Esta política explica qué información utiliza Vitis & Co., para qué la necesita, cómo se protege y cómo puedes solicitar su corrección o eliminación. La plataforma es un proyecto académico demostrativo.

1. Responsable y contacto

El responsable de administrar los datos que la aplicación registra es Luis Facundo Barrios Gutiérrez, estudiante y desarrollador del proyecto.

Para consultas, correcciones o solicitudes de eliminación, escribe a darelik015@gmail.com.

2. Datos recopilados y minimización

La aplicación utiliza únicamente los datos necesarios para sus funciones:

  • Datos de contacto opcionales: nombre, teléfono y dirección que el cliente decida proporcionar al realizar un pedido. No se solicita correo electrónico al cliente en el formulario de compra.
  • Datos del pedido: número, fecha, productos, cantidades, precios, total y estado. Se necesitan para registrar el pedido, actualizar existencias y generar el historial y los reportes administrativos.
  • Datos de acceso administrativo: nombre de usuario y un token temporal de sesión. La contraseña administrativa se configura en variables de entorno y no se guarda en la tabla de pedidos.
  • Datos técnicos de conexión: el servidor web puede registrar dirección IP, hora y recurso solicitado en sus registros técnicos para operar y diagnosticar el servicio. Su retención depende de la configuración del alojamiento.

El historial sintético de inventario y los datos usados para el pronóstico son datos de demostración y no representan información personal de clientes.

3. Finalidades y consentimiento

El nombre, teléfono y dirección solo se utilizan para identificar el pedido y facilitar el contacto o la coordinación de su entrega. Los datos del pedido se usan para mantener el inventario, consultar el historial y producir reportes. El sistema no usa esos datos para publicidad.

Antes de confirmar cualquier pedido debes marcar la casilla de autorización que enlaza a esta política. La aplicación rechaza pedidos sin esa aceptación expresa y registra la fecha y hora del consentimiento junto al pedido. El nombre, teléfono y dirección siguen siendo opcionales; puedes dejarlos en blanco y aceptar el tratamiento de los datos necesarios para registrar la compra.

Los datos personales no se venden ni alquilan. No se ceden a terceros para fines comerciales. Cuando el proyecto está alojado en la Nube Universitaria, los datos se encuentran en su infraestructura únicamente para prestar el alojamiento académico y conforme a sus reglas; cualquier otra comunicación requiere autorización previa, salvo obligación legal aplicable.

4. Almacenamiento y medidas de seguridad

Los pedidos y datos de contacto se guardan en una base SQLite dentro del volumen persistente de Docker. El acceso a las funciones administrativas está protegido por autenticación y un token de sesión, y solo la cuenta administrativa configurada puede consultar el historial. No existe un sistema de múltiples roles.

La contraseña administrativa se suministra mediante variables de entorno: la aplicación no la guarda en la base de datos ni la hashea actualmente. El token se mantiene en la sesión del navegador y en memoria del servidor. Por ello, el archivo local .env debe mantenerse privado y con acceso restringido.

La configuración local de Docker usa HTTP en http://localhost:8080 y no cifra el tráfico con TLS. No ingreses datos personales a través de una conexión pública sin HTTPS. Si la plataforma se publica en la Nube Universitaria, el HTTPS/TLS debe estar habilitado y confirmado por la configuración institucional de alojamiento.

El volumen de Docker conserva los datos, pero el proyecto no configura respaldos periódicos automáticos ni cifrado de la base de datos en disco. El responsable debe gestionar copias de seguridad protegidas si el entorno de alojamiento lo requiere.

5. Conservación, actualización y eliminación

Actualmente no hay una eliminación automática por antigüedad. Para consultar, corregir o solicitar la eliminación de tus datos, escribe al correo de contacto con el asunto “Solicitud de privacidad” e indica el número del pedido y la acción solicitada. No envíes contraseñas ni documentos sensibles por correo.

El responsable verificará la solicitud de manera razonable y la atenderá manualmente. Si se solicita eliminar los datos de contacto, se quitarán del pedido el nombre, teléfono, dirección y la marca de consentimiento; el registro restante se conservará sin esos datos personales para mantener la consistencia del historial de inventario y reportes. Los registros técnicos administrados por el proveedor de alojamiento pueden requerir una solicitud separada conforme a sus propias reglas de retención.

6. Alojamiento académico y cambios

La UAJMS facilita únicamente el entorno de alojamiento académico cuando esta aplicación se encuentra en la Nube Universitaria. El tratamiento de los registros técnicos del servicio también puede estar sujeto a la Política de Uso Aceptable (AUP) vigente. Esta página no sustituye la AUP ni las disposiciones legales aplicables.

La política puede actualizarse cuando cambien las funciones o el entorno de alojamiento. La versión vigente estará disponible en esta página.
